# SylvMusic 🎵

SylvMusic is a modern audio player built with Kotlin.

## Core Capabilities
* **Streaming & Caching:** Stream fluidly from public endpoints with offline download and local library integration.
* **Premium Audio Pipeline:** Native support for gapless playback, custom crossfade ranges, and advanced audio backend utilities.
* **Polished Interface:** Apple-inspired clean visual design built dynamically on top of modern Kotlin rendering frameworks.

## Project Origin & Credits
This repository is a downstream variation of **BitChord**. We extend our immense gratitude to the original project and all its open-source contributors for establishing the playback architecture, UI templates, and media sessions handling.

## Development & Building
Because this project utilizes a multi-module architecture, ensure you have the appropriate ecosystem components ready before compiling:

* **IDE:** Android Studio / IntelliJ IDEA (Latest Stable Build)
* **SDK:** JDK 17+ configured as your Gradle build runner
* **Build Configuration:** Run a complete sync on `build.gradle.kts` to pull the media engines and layout components.
